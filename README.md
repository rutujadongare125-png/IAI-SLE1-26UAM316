## Project Description
This project implements a basic rule-based AI agent using Python. The agent accepts a user's problem and provides a suggestion based on predefined rules.

## Features
- Suggests making a study timetable.
- Suggests taking rest when the user feels tired.
- Suggests practising Python when the user mentions Python.
- Provides a default suggestion for other inputs.

## How to Run
Run the following command in a terminal:

`python agent.py`
